# Ispravak Uredbe o privremenom preuzimanju i upravljanju određenom imovinom

## ISPRAVAK

### UREDBE O PRIVREMENOM PREUZIMANJU I UPRAVLJANJU ODREĐENOM
IMOVINOM

U članku 2. stavku 2. umjesto riječi "napustile Republike Hrvatsku"
trebaju stajati riječi "napustile Republiku Hrvatsku".

U članku 4. stavku 2. umjesto riječi "osniva Komisija" trebaju
stajati riječi "osniva Komisiju".

U članku 4. stavku 3. umjesto "Ministarstva obnove" treba
stajati "Ministarstva obrane"
