# Rješenje o razrješenju predsjednika, zamjenice predsjednika, tajnika i zamjenice tajnika hrvatskog dijela Stalne hrvatsko-mađarske komisije za vodno gospodarstvo

VLADA REPUBLIKE HRVATSKE

2340

Na temelju članka 31. stavka 4. Zakona o Vladi Republike Hrvatske (»Narodne novine«, broj 150/2011) i članka 10. stavka 2. Sporazuma o vodnogospodarskim odnosima između Vlade Republike Hrvatske i Vlade Republike Mađarske (»Narodne novine – Međunarodni ugovori«, broj 10/94), Vlada Republike Hrvatske je na sjednici održanoj 13. rujna 2012. godine donijela

RJEŠENJE

O RAZRJEŠENJU PREDSJEDNIKA, ZAMJENICE PREDSJEDNIKA, TAJNIKA I ZAMJENICE TAJNIKA HRVATSKOG DIJELA STALNE HRVATSKO-MAĐARSKE KOMISIJE ZA VODNO GOSPODARSTVO

1. Razrješuje se ZDRAVKO KRMEK dužnosti predsjednika hrvatskog dijela Stalne hrvatsko-mađarske komisije za vodno gospodarstvo.

2. Razrješuje se RUŽICA DRMIĆ dužnosti zamjenice predsjednika hrvatskog dijela Stalne hrvatsko-mađarske komisije za vodno gospodarstvo.

3. Razrješuje se ŽELJKO OSTOJIĆ dužnosti tajnika hrvatskog dijela Stalne hrvatsko-mađarske komisije za vodno gospodarstvo.

4. Razrješuje se SANJA GENZIĆ JURIŠEVIĆ dužnosti zamjenice tajnika hrvatskog dijela Stalne hrvatsko-mađarske komisije za vodno gospodarstvo.
