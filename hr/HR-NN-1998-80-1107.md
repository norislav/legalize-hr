# Rješenje o razrješenju Dubravka Novaka dužnosti člana Savjeta Hrvatskog centra za mine

# VLADA REPUBLIKE HRVATSKE

Na temelju članka 23. stavka 4. Zakona o Vladi Republike Hrvatske ("Narodne
novine", br. 41/90, 8/91, 14/91, 53A/91, 9/92, 55/92 i 29/94) i članka
4. stavka 2. Uredbe o osnivanju Hrvatskog centra za mine ("Narodne
novine", br. 24/98 i 32/98), Vlada Republike Hrvatske je na sjednici
održanoj 4. lipnja 1998. godine donijela

Razrješuje se DUBRAVKO NOVAK dužnosti člana Savjeta Hrvatskog centra
