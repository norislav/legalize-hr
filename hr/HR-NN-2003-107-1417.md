## Pravilnik

### o izmjenama i dopunama Pravilnika

o homologaciji vozila

### Članak
1.

U
Pravilniku o homologaciji vozila (»Narodne novine« broj 15/02, 88/03 i 28/03)
PRILOG 3. se mijenja prema sljedećem:

1. U
tablici »POPIS ECE PRAVILNIKA« u stupcu 4. u redu pod rednim brojem 20. umjesto
»03« treba stajati »04«, u redovima pod rednim brojevima 38., 54., 55., umjesto
»00« treba stajati »01«, u redu pod rednim brojem 41 umjesto »02« treba stajati
»03 4«. Na kraju tablice dodaje se
nova bilješka koja glasi »(4) Za
rabljena vozila primjenjuje se ECE Pravilnik s 02 nizom izmjena i dopuna,
razina zahtjeva B.«

Također, dodaju se u tablici
ova dva nova reda:

| 85 | Veliki autobusi – konstrukcijske |  |  |  |
| --- | --- | --- | --- | --- |
|  | značajke | 36 | 03 | M2, M3 |
| 86 | Posebna  oprema motornih vozila |  |  |  |
|  | koja  upotrebljavaju UNP kao |  |  |  |
|  | gorivo | 67 | 00 | M, N |

2. U tablici »POPIS EU SMJERNICA« u stupcu 3. u redu pod rednim brojem 32.
umjesto »77/358/EEC« treba stajati »77/538/EEC«, u redu pod rednim brojem 73.
umjesto »00/40/EC« treba stajati »2000/40/EC« i u redu pod rednim brojem 41.
umje­sto »91/542B/EEC« treba stajati »1999/96/EC 4«. Na kraju tablice dodaje se
nova bilješka koja glasi »(4) Za
rabljena vozila primje­njuje se EU smjernica 91/542/EEC s razinom zahtjeva B.«

Također, dodaje se u tablici ovaj novi red:
