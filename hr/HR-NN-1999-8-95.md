# Odluka o dopuni Odluke o određivanju robe koja se izvozi i uvozi na temelju dozvola

# **VLADA REPUBLIKE HRVATSKE**

Na temelju članka 46. Zakona o trgovini ("Narodne novine", broj 11/96
i 101/98), Vlada Republike Hrvatske je na sjednici održanoj 21. siječnja
1999. godine, donijela

## **ODLUKU**

### **O DOPUNI ODLUKE O ODREĐIVANJU ROBE KOJA SE IZVOZI I
UVOZI NA TEMELJU DOZVOLA**

I.

U Odluci o određivanju robe koja se izvozi i uvozi na temelju dozvola
("Narodne novine", broj 58/96, 67/96, 15/97 i 132/98) u točki II. dodaju
se sljedeći tarifni brojevi i tarifne oznake Carinske tarife:

| Tarifni      broj | Tarifna      oznaka | Naziv |
| --- | --- | --- |
| 47.07 |  | Papir i karton namijenjeni ponovnoj pre-    radi (reciklaži): |
|  | 4707.10 | - nebijeljeni kraft-papir ili karton ili va-    loviti papir ili karton |
|  | 4707.20 | - papir ili karton dobiven uglavnom od    bijeljene kemijske celuloze, neobojen u masi |
|  | 4707.30 | - papir ili karton dobiven uglavnom od    drvenjače (novine, časopisi i slični tiskani materijali): |
|  | 4707.301 | --- novinski otpaci i ostaci |
|  | 4707.90 | - ostalo, uključujući nesortirane otpatke i ostatke |

II.

Ova Odluka stupa na snagu osmog dana od dana objave u "Narodnim novinama".
