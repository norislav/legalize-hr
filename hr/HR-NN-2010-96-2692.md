# Uredba o utvrđivanju visine boravišne pristojbe za 2011. godinu

VLADA REPUBLIKE HRVATSKE

2692

Na temelju članka 16. i članka 20. stavka 7. Zakona o boravišnoj pristojbi (»Narodne novine« br. 152/2008 i 59/2009), Vlada Republike Hrvatske je na sjednici održanoj 4. kolovoza 2010. godine donijela

UREDBU

O UTVRĐIVANJU VISINE BORAVIŠNE PRISTOJBE ZA 2011. GODINU

### Članak 1.

Visina boravišne pristojbe za 2011. godinu utvrđuje se u sljedećim iznosima:

| Razred turističkog mjesta | Boravišna pristojba u kunama po osobi i noćenju |  |  |
| --- | --- | --- | --- |
| Za razdoblje |  |  |  |
| I. glavna sezona | II. predsezona i posezona | III. izvansezona |  |
| A | 7,00 | 5,50 | 4,50 |
| B | 6,00 | 4,50 | 3,50 |
| C | 5,00 | 3,50 | 2,50 |
| D i ostala nerazvrstana mjesta | 4,00 | 2,50 | 2,00 |

### Članak 2.

Boravišna pristojba za građane koji pružaju ugostiteljske usluge smještaja u domaćinstvu i seljačkom domaćinstvu utvrđuje se u iznosu od 300 kuna po krevetu i kamp-jedinici, ovisi o razredu turističkog mjesta i o koeficijentu i iznosi:

| Razred turističkog mjesta | Koeficijent | Iznos u kunama |
| --- | --- | --- |
| A | 1,00 | 300,00 |
| B | 0,85 | 255,00 |
| C | 0,70 | 210,00 |
| D i ostala nerazvrstana mjesta | 0,50 | 150,00 |

### Članak 4.

Boravišna pristojba u ostalim mjestima koja nisu razvrstana u razrede uplaćuje se sukladno D-razredu turističkog mjesta.

### Članak 5.

Iznos dijela boravišne pristojbe koji se uplaćuje na posebni račun Hrvatske turističke zajednice i koji se namjenski koristi za razvojne projekte i programe kreiranja novih turističkih programa u turistički nerazvijenim područjima, utvrđuje se u iznosu od 2,5 % od ukupno uplaćenih sredstava na račun utvrđen propisima o prihodima za javne potrebe.
