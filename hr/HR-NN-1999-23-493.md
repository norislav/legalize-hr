# Rješenje o imenovanju predsjednika i članova Upravnog vijeća Doma zdravlja Ministarstva unutarnjih poslova

# VLADA REPUBLIKE HRVATSKE

Na temelju članka 30. stavka 4. Zakona o Vladi Republike Hrvatske ("Narodne
novine", broj 101/98) i članka 49. stavka 4. Zakona o zdravstvenoj zaštiti
("Narodne novine", broj 1/97), Vlada Republike Hrvatske je na sjednici
održanoj 4. ožujka 1999. godine donijela

## **RJEŠENJE**

### **O IMENOVANJU PREDSJEDNIKA I ČLANOVA UPRAVNOG VIJEĆA
DOMA ZDRAVLJA MINISTARSTVA UNUTARNJIH POSLOVA**

1. Imenuje se DRAŽEN IVANUŠEC predsjednikom Upravnog vijeća Doma zdravlja
Ministarstva unutarnjih poslova.

2. Za članove Upravnog vijeća Doma zdravlja Ministarstva unutarnjih
poslova, imenuju se:

- prof. dr. sc. DUBRAVKO ORLIĆ

- prof. IGOR JELOVAC

- TIHOMIR GORŠE

- IVAN BABIĆ.

Klasa: 080-02/99-01/32

Urbroj: 50304/2-99-01

Zagreb, 4. ožujka 1999.

Predsjednik

**mr. Zlatko Mateša, **v. r.
