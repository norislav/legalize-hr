# Rješenje o razrješenju zamjenice državnog tajnika Središnjeg državnog ureda za upravljanje državnom imovinom

# VLADA REPUBLIKE HRVATSKE

**3123**

Na temelju članka 30. stavka 4. Zakona o Vladi Republike Hrvatske (»Narodne
novine«, br. 101/98, 15/2000, 117/2001, 199/2003 i 30/2004) i članka 11. stavka
3. Uredbe o unutarnjem ustrojstvu Središnjeg državnog ureda za upravljanje
državnom imovinom (»Narodne novine«, br. 11/2004, 121/2004 i 27/2008), Vlada
Republike Hrvatske je na sjednici održanoj 4. rujna 2008. godine donijela

## RJEŠENJE

### O RAZRJEŠENJU ZAMJENICE DRŽAVNOG TAJNIKA SREDIŠNJEG DRŽAVNOG UREDA ZA
UPRAVLJANJE DRŽAVNOM IMOVINOM

Razrješuje se KATARINA ČOP BAJDE dužnosti zamjenice državnog tajnika Središnjeg
državnog ureda za upravljanje državnom imovinom.

Klasa: 080-02/08-02/388

Urbroj: 50304/2-08-01

Zagreb, 4. rujna 2008.
