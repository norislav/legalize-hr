# Odluka o utvrđivanju visine boravišne pristojbe za 1999. godinu

# VLADA REPUBLIKE HRVATSKE

Na temelju članka 8. stavka 1. Zakona o boravišnoj pristojbi ("Narodne
novine", broj 35/95 - pročišćeni tekst i 44/98), Vlada Republike Hrvatske
je na sjednici održanoj 2. srpnja 1998. godine donijela

## ODLUKU

### O UTVRĐIVANJU VISINE BORAVIŠNE PRISTOJBE ZA 1999. GODINU

I.

Boravišna pristojba za 1999. godinu utvrđuje se u slijedećim iznosima:

| Razred  turističkog  mjesta | Boravišna pristojba u kunama po osobi i noćenju |  |  |
| --- | --- | --- | --- |
| Za razdoblje |  |  |  |
| I. glavna  sezona | II. predsezona  i posezona | III. vanse-  zona |  |
| A | 7,00 | 5,50 | 4,50 |
| B | 6,00 | 4,50 | 3,50 |
| C | 5,00 | 3,50 | 2,50 |
| D  i ostala nerazvr-  stana mjesta | 4,00 | 2,50 | 2,00 |

Ova Odluka stupa na snagu danom objave u "Narodnim novinama", a primjenjuje
se od 1. siječnja 1999. godine.
