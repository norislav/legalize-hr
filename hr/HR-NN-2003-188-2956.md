## ODLUKU

### O VISINI NAKNADE ZA POLAGANJE VOZAČKOG ISPITA

### Članak
1.

Visine naknada za polaga­­nje vozačkog ispita po
pojedinom nastavnom predmetu iznose:

| Red. |  | Visina naknade |
| --- | --- | --- |
| broj | Naziv  nastavnog predmeta | u kunama |
| 1 | 2 | 3 |
| 1. | Pruža­­nje  prve pomoći | 75,00 |
| 2. | Prometna i  sigurnosna pravila | 93,00 |
| 3. | Uprav­­lja­­nje  vozilom na motorni pogon  (za kate­goriju ili vrstu vozila) |  |
| 3.1. | A, H | 130,00 |
| 3.2. | B | 150,00 |
| 3.3. | B+E, G | 160,00 |
| 3.4. | C | 195,00 |
| 3.5. | C+E | 210,0 |
| 3.6. | D, D+E, F | 240,00 |

### Članak 2.

U naknadama
iz članka 1. ove odluke sadržan je porez na dodanu vrijednost.

### Članak 3.

Naknadu za polaga­­nje vozačkog ispita snosi kandidat
za vozača koji se prijavio za polaga­­nje vozačkog ispita.

### Članak 4.

Ova Odluka na snagu stupa osmog dana od dana objave u
»Narodnim novinama«, kada prestaje važiti Odluka o visini naknade za polaga­­nje
vozačkog ispita broj 5099 od 22. srp­­nja 1998. godine, objav­­ljena u
»Narodnim novinama«, broj 106/98.
