# Rješenje o razrješenju Milana Radoševića položaja savjetnika potpredsjednika Vlade Republike Hrvatske

# VLADA REPUBLIKE HRVATSKE

Na temelju članka 23. stavka 4. Zakona o Vladi Republike Hrvatske ("Narodne
novine", br. 41/90, 8/91, 14/91, 53A/91, 9/92, 55/92 i 29/94) i članka
8. stavka 2. Uredbe o Stručnoj službi Vlade Republike Hrvatske ("Narodne
novine", broj 52/90), Vlada Republike Hrvatske je na sjednici održanoj
6. lipnja 1996. godine donijela

## **RJEŠENJE**

### **O RAZRJEŠENJU SAVJETNIKA POTPREDSJEDNIKA VLADE REPUBLIKE
HRVATSKE**

Razrješuje se MILAN RADOŠEVIĆ položaja savjetnika potpredsjednika Vlade
Republike Hrvatske s danom 31. srpnja 1996.

Klasa: 080-02/96-02/61

Urbroj: 50304/2-96-01

Zagreb, 6. lipnja 1996.
