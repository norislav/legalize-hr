# Rješenje o razrješenju ravnateljice Agencije za osiguranje radničkih potraživanja u slučaju stečaja poslodavca

VLADA REPUBLIKE HRVATSKE

711

Na temelju članka 31. stavka 4. Zakona o Vladi Republike Hrvatske (»Narodne novine« broj 150/2011), članka 11. stavka 2. Zakona o osiguranju potraživanja radnika u slučaju stečaja poslodavca (»Narodne novine« broj 86/2008), članka 22. stavka 2. Statuta Agencije za osiguranje radničkih potraživanja u slučaju stečaja poslodavca (»Narodne novine« broj 50/2009) i članka 6. stavka 2. Zakona o postupku primopredaje vlasti (»Narodne novine« br. 94/2004, 17/2007 i 91/2010), Vlada Republike Hrvatske je na sjednici održanoj 16. veljače 2012. godine donijela

RJEŠENJE

O RAZRJEŠENJU RAVNATELJICE AGENCIJE ZA OSIGURANJE RADNIČKIH POTRAŽIVANJA U SLUČAJU STEČAJA POSLODAVCA

Razrješuje se VESNA VITEZ dužnosti ravnateljice Agencije za osiguranje radničkih potraživanja u slučaju stečaja poslodavca.

Klasa: 080-02/12-02/180

Urbroj: 5030115/1-12-01

Zagreb, 16. veljače 2012.
