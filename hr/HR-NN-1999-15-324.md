# Rješenje o razrješenju Vladimira Kuzijeva, dužnosti pomoćnika ravnateljice Hrvatskog zavoda za zapošljavanje

# VLADA REPUBLIKE HRVATSKE

Na temelju članka 30. stavka 4. Zakona o Vladi Republike Hrvatske ("Narodne
novine", broj 101/98) i članka 23. stavka 2. Statuta Hrvatskog zavoda za
zapošljavanje ("Narodne novine", broj 4/98), Vlada Republike Hrvatske je
na sjednici održanoj 4. veljače 1999. godine donijela

## **RJEŠENJE**

### **O RAZRJEŠENJU POMOĆNIKA RAVNATELJICE HRVATSKOG ZAVODA
ZA ZAPOŠLJAVANJE**

Razrješuje se VLADIMIR KUZIJEV dužnosti pomoćnika ravnateljice Hrvatskog
zavoda za zapošljavanje.

Klasa: 080-02/99-02/11

Urbroj: 50304/2-99-01

Zagreb, 4. veljače 1999.
