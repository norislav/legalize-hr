# Odluka o preferencijalnoj carinskoj kvoti pri uvozu određenih poljoprivrednih proizvoda

# VLADA REPUBLIKE HRVATSKE

**3048**

Na temelju članka 14. stavka 2. Zakona o poljoprivredi (»Narod­ne novine«, br.
66/2001 i 83/2002), članka 4. Zakona o carinskoj tarifi (»Narodne novine«, br.
61/2000 i 117/2000) i članka 30. stavka 2. Zakona o Vladi Republike Hrvatske
(»Narodne novine«, br. 101/98, 15/2000, 117/2001, 199/2003 i 30/2004), Vlada
Republike Hrvatske je na sjednici održanoj 7. prosinca 2006. godine donijela

## ODLUKU

### O PREFERENCIJALNOJ CARINSKOJ KVOTI PRI UVOZU ODREĐENIH POLJOPRIVREDNIH PROIZVODA

I.

Utvrđuju se preferencijalne carinske kvote pri uvozu sljedećih poljoprivrednih
proizvoda:

| Tarifna oznaka | Naziv   proizvoda | Preferencijalna carinska kvota (tona) | Preferencijalna stopa carine unutar kvote |
| --- | --- | --- | --- |
| 1003 00 | Ječam: |  |  |
| 1003 00 90 | - ostali | 50.000 | 0% |
| 1005 | Kukuruz: |  |  |
| 1005 90 00 | - ostali |  |  |
| 1005 90 00 10 | - - ex. žuti | 300.000 | 0% |

II.

Preferencijalne carinske kvote za proizvode iz točke I. ove Odluke, primjenjuju
se pri uvozu iz zemalja s kojima je Republika Hrvatska sklopila Ugovor o
slobodnoj trgovini ili Sporazum o stabilizaciji i pridruživanju.

III.

Stopa carine koja se primjenjuje na uvoz količina izvan kvota utvrđenih ovom
Odlukom je osnovna stopa carine ili snižena stopa carine pri uvozu roba
podrijetlom iz zemalja s kojima je Republika Hrvatska sklopila ugovor o
povlaštenom trgovinskom režimu navedena u Uredbi o Carinskoj tarifi za 2006.
godinu (»Narodne novine«, br. 145/2005, 149/2005, 11/2006, 37/2006, 46/2006,
85/2006, 91/2006 i 117/2006), odnosno u Uredbi o Carinskoj tarifi za 2007.
godinu.

IV.

Carinsku kvotu, koja je predmet ove Odluke, raspodjeljivat će međuresorno
Povjerenstvo, imenovano na temelju Uredbe o raspodjeli carinskih kvota za
poljoprivredno-prehrambene proizvode podrijetlom iz zemalja članica Svjetske
trgovinske organizacije i zemalja s kojima je Republika Hrvatska sklopila Ugovor
o slobod­noj trgovini i Sporazum o stabilizaciji i pridruživanju (»Narodne
novine«, br. 55/2004, 146/2004 i 138/2005), a polazeći od kriterija utvrđenih
predmetnom Uredbom.

V.

Zadužuje se Ministarstvo poljoprivrede, šumarstva i vodnoga gospodarstva za
provedbu ove Odluke, putem natječaja, koji će biti objavljen u »Narodnim
novinama«.

VI.

Ova Odluka primjenjuje se do 30. lipnja 2007. godine.

VII.

Ova Odluka stupa na snagu danom donošenja, a objavit će se u »Narodnim
novinama«.
