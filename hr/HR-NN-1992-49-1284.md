# Rješenje o imenovanju povjerenika Vlade Republike Hrvatske u općini Vojnić

# VLADA REPUBLIKE HRVATSKE

Na temelju ovlasti iz članka 17b. stavka 3. Zakona o Vladi Republike
Hrvatske ("Narodne novine", broj 41/90, 8/91.14/91. 53A/91 i
9/92), i članka 4. Odluke o poduzimanju posebnih mjera u općini Vojnić.
Vlada Republike Hrvatske na sjednici održanoj 4. kolovoza 1992. godine,
donijela je

## RJEŠENJE

### o imenovanju povjerenika Vlade Republike Hrvatske u općini
Vojnić

1. Za povjerenika Vlade Republike Hrvatske u općini Vojnić imenuje se
MIRKO PUTRIĆ, koji obnaša funkciju povjerenika Vlade Republike Hrvatske
za općinu Vrginmost.

2. Povjerenik Vlade dužan je nastupiti danom primitka ovog rješenja.

3. Povjerenik Vlade imenovat će svoje pomoćnike bez odgađanja.

4. Ovo rješenje objavljuje se u "Narodnim novinama".
