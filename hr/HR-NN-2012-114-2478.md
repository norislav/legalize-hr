# Rješenje o razrješenju članice Upravnog odbora Umirovljeničkog fonda

VLADA REPUBLIKE HRVATSKE

2478

Na temelju članka 31. stavka 4. Zakona o Vladi Republike Hrvatske (»Narodne novine«, broj 150/2011) i članka 14. stavka 2. Zakona o Umirovljeničkom fondu (»Narodne novine«, br. 93/2005, 41/2007 i 90/2011), Vlada Republike Hrvatske je na sjednici održanoj 4. listopada 2012. godine donijela

RJEŠENJE

O RAZRJEŠENJU ČLANICE UPRAVNOG ODBORA UMIROVLJENIČKOG FONDA

Razrješuje se LJILJANA CVJETOVIĆ dužnosti članice Upravnog odbora Umirovljeničkog fonda, radi odlaska na novu dužnost.

Klasa: 080-02/12-02/534

Urbroj: 5030115/1-12-02

Zagreb, 4. listopada 2012.
