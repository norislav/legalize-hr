# Rješenje o imenovanju Vedrana Bajsića savjetnikom potpredsjednice Vlade Republike Hrvatske

# VLADA REPUBLIKE HRVATSKE

Na temelju članka 23. stavka 4. Zakona o Vladi Republike Hrvatske ("Narodne
novine", br. 41/90, 8/91, 14/91, 53A/91, 9/92, 55/92 i 29/94) i članka
8. stavka 2. Uredbe o Stručnoj službi Vlade Republike Hrvatske ("Narodne
novine", broj 52/90), Vlada Republike Hrvatske je na sjednici održanoj
26. veljače 1998. godine donijela

## **RJEŠENJE**

### **O IMENOVANJU SAVJETNIKA POTPREDSJEDNICE VLADE REPUBLIKE
HRVATSKE**

Imenuje se VEDRAN BAJSIĆ savjetnikom potpredsjednice Vlade Republike
Hrvatske.

Klasa: 080-02/98-01/21

Urbroj: 50304/2-98-01

Zagreb, 26. veljače 1998.
