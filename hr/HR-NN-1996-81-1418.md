# Rješenje o razrješenju mr. Zlatka Dominikovića dužnosti ravnatelja Hrvatskog stočarsko selekcijskog centra

# VLADA REPUBLIKE HRVATSKE

Na temelju članka 23. stavka 4. Zakona o Vladi Republike Hrvatske ("Narodne
novine", broj 41/90, 8/91, 14/91, 53A/91, 9/92, 55/92 i 29/94) i članka
4. stavka 3. Uredbe o Hrvatskom stočarsko selekcijskom centru ("Narodne
novine", broj 63/94), Vlada Republike Hrvatske je na sjednici održanoj
26. rujna 1996. godine donijela

## **RJEŠENJE**

### **O RAZRJEŠENJU RAVNATELJA HRVATSKOG STOČARSKO SELEKCIJSKOG
CENTRA **

Razrješuje se mr. ZLATKO DOMINIKOVIĆ dužnosti ravnatelja Hrvatskog stočarsko
selekcijskog centra.

Klasa: 080-02/96-02/80

Urbroj: 50304/2-96-01

Zagreb, 26. rujna 1996.
