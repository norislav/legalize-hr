# Rješenje o imenovanju predsjednika i članova Upravnog vijeća Hrvatskog stočarsko selekcijskog centra

# VLADA REPUBLIKE HRVATSKE

Na temelju članka 23. stavka 4. Zakona o Vladi Republike Hrvatske
(Narodne novine, broj 41/90, 8/91, 14/91 53A/91, 9/92, 55/92 i 29/94) i
članka 4. 5tavka 3. Uredbe o Hrvatskom stočarsko selekcijskom
centru (Narodne novine, broj 63/94), Vlada Republike Hrvatske je na sjednici
19. siječnja 1995. godine donijela

## Rješenje

### o imenovanju predsjednika i članova Upravnog vijeća
Hrvatskog stočarsko selekcijskog centra

1. Imenuje se ANTUN ŠEDA predsjednikom Upravnog vijeća Hrvatskog
stočarsko selekcijskog centra.

2. Za članove Upravnog vijeća Hrvatskog stočarsko
selekcijskog centra imenuju se:

- IVO KUŠTRAK

- JOSIP PANKRETIĆ.

Klasa: 080-02/94-06/36

Urbroj: 50304/2-95-01

Zagreb, 19. siječnja 1995
