# Rješenje o imenovanju privremenog ravnatelja Javne ustanove Hrvatski olimpijski centar

# VLADA REPUBLIKE HRVATSKE

**1611**

Na temelju članka 30. stavka 4. Zakona o Vladi Republike Hrvatske (»Narodne
novine«, br. 101/98, 15/2000, 117/2001, 199/2003 i 30/2004) i članka 18. Uredbe
o osnivanju Javne ustanove Hrvatski olimpijski centar (»Narodne novine«, broj
142/2006), Vlada Republike Hrvatske je na sjednici održanoj 4. svibnja 2007.
godine donijela

### O IMENOVANJU PRIVREMENOG RAVNATELJA JAVNE USTANOVE HRVATSKI OLIMPIJSKI CENTAR

Imenuje se TOMISLAV PAŠKVALIN privremenim ravnateljem Javne ustanove Hrvatski
olimpijski centar.
