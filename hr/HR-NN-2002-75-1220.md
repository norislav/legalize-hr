# Uredba o utvrđivanju visine boravišne pristojbe za 2003. godinu

# VLADA REPUBLIKE HRVATSKE

1220

Na teme­lju članka 8. stavka 1. Zakona o boravišnoj pristojbi (»Narodne
novine«, br. 35/95 – pročišćeni tekst i 64/2000), Vlada Republike Hrvatske je
na sjednici održanoj 20. lip­nja 2002. godine, donijela

## UREDBU

### O UTVRĐIVANJU VISINE BORAVIŠNE PRISTOJBE ZA 2003. GODINU

### Članak 1.

Boravišna pristojba za 2003. godinu utvrđuje
se u s­ljedećim iznosima:

| Razred  turističkog  mjesta | Boravišna  pristojba u kunama po  osobi  i noće­nju |  |  |
| --- | --- | --- | --- |
|  | Za  razdob­lje |  |  |
|  | I. glavna | II.  predsezona | III. izvansezona |
|  | sezona | i  posezona |  |
| A | 7,00 | 5,50 | 4,50 |
| B | 6,00 | 4,50 | 3,50 |
| C | 5,00 | 3,50 | 2,50 |
| D i ostala |  |  |  |
| nerazvrstana  mjesta | 4,00 | 2,50 | 2,00 |

### Članak 2.

Visina paušalnog iznosa boravišne pristojbe iz članka 12. Zakona o
boravišnoj pristojbi koja je izražena u DEM, određuje se u EUR, prema
konverzijskom tečaju koji iznosi 1,95583.

### Članak 3.

Ova Uredba stupa na snagu
osmog dana od dana objave u »Narodnim novinama«.
