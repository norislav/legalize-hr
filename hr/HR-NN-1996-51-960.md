# Rješenje o imenovanju prof. dr. Pave Caputa predsjednikom Upravnog vijeća Hrvatskog stočarskog selekcijskog centra

# VLADA REPUBLIKE HRVATSKE

Na temelju članka 23. stavka 4. Zakona o Vladi Republike Hrvatske ("Narodne
novine", broj 41/90, 8/91, 14/91, 53A/91, 9/92, 55/92 i 29/94) i članka
4. stavka 3. Uredbe o Hrvatskom stočarsko selekcijskom centru ("Narodne
novine", broj 63/94), Vlada Republike Hrvatske je na sjednici održanoj
20. lipnja 1996. godine donijela

## **RJEŠENJE**

### **O IMENOVANJU PREDSJEDNIKA UPRAVNOG VIJEĆA HRVATSKOG
STOČARSKO SELEKCIJSKOG CENTRA**

Imenuje se prof. dr. PAVO CAPUT predsjednikom Upravnog vijeća Hrvatskog
stočarsko selekcijskog centra.

Klasa: 080-02/96-05/10

Urbroj: 50304/2-96-01

Zagreb, 20. lipnja 1996.

Predsjednik
