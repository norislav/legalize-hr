# Rješenje kojim se društvu za upravljanje investicijskim fondovima ZB Invest d.o.o., Zagreb, daje suglasnost na pripajanje otvorenih investicijskih fondova s javnom ponudom Select Novčani, Select Eurobond i Select Europe otvorenom investicijskom fondu s javnom ponudom ZB euroaktiv

HRVATSKA AGENCIJA ZA NADZOR FINANCIJSKIH USLUGA

1166

Na temelju odredbi članka 15. točka 4. alineja 1. i članka 8. stavak 1. Zakona o Hrvatskoj agenciji za nadzor financijskih usluga (»Narodne novine«, broj 140/05), članka 181. stavak 1. Zakona o investicijskim fondovima (»Narodne novine«, broj 150/05), članka 6. Pravilnika o sadržaju i vođenju registra fondova (»Narodne novine«, broj 29/06) i članka 4. stavka 2. Pravilnika o postupku, uvjetima i načinu pripajanja otvorenih investicijskih fondova (»Narodne novine«, broj 139/06), Hrvatska agencija za nadzor financijskih usluga, na zahtjev društva za upravljanje investicijskim fondovima ZB Invest d.o.o., Zagreb, Ivana Lučića, u predmetu pripajanja otvorenih investicijskih fondova Select Novčani, Select Eurobond i Select Europe otvorenom investicijskom fondu ZB euroaktiv, 1. travnja 2010. godine donosi:

RJEŠENJE

1. Društvu za upravljanje investicijskim fondovima ZB Invest d.o.o., Zagreb, Ivana Lučića 2a, daje se suglasnost na pripajanje otvorenih investicijskih fondova s javnom ponudom Select Novčani, Select Eurobond i Select Europe otvorenom investicijskom fondu s javnom ponudom ZB euroaktiv.

2. Danom pripajanja, otvoreni investicijski fond s javnom ponudom Select Novčani, koji se vodi pod identifikacijskim brojem JPN031, otvoreni investicijski fond s javnom ponudom Select Europe koji se vodi pod identifikacijskim brojem JPD012 i otvoreni investicijski fond s javnom ponudom Select Eurobond koji se vodi pod identifikacijskim brojem JPO014, brišu se iz registra fondova.

3. Ovo rješenje objavit će se u »Narodnim novinama«.

Obrazloženje

Hrvatska agencija za nadzor financijskih usluga (dalje: Agencija), zaprimila je 2. ožujka 2010. zahtjev društva za upravljanje investicijskim fondovima ZB Invest d.o.o., Zagreb, Ivana Lučića 2a (dalje: Društvo), za izdavanje suglasnosti za pripajanje otvorenih investicijskih fondova Select Novčani, Select Eurobond i Select Europe otvorenom investicijskom fondu ZB euroaktiv, sukladno odredbama članka 3. stavka 4. Pravilnika o postupku, uvjetima i načinu pripajanja otvorenih investicijskih fondova (»Narodne novine«, broj 139/06, dalje: Pravilnik).

Uz zahtjev je bila dostavljena sva dokumentacija sukladno odredbama članka 3. stavka 5. Pravilnika i to kako slijedi:

1. Odluka Nadzornog odbora Društva o pripajanju otvorenog investicijskog fonda Select Novčani otvorenom investicijskom fondu fondu s javnom ponudom ZB euroaktiv,

2. Odluka Nadzornog odbora Društva o pripajanju otvorenog investicijskog fonda Select Eurobond otvorenom investicijskom fondu fondu s javnom ponudom ZB euroaktiv,

3. Odluka Nadzornog odbora Društva o pripajanju otvorenog investicijskog fonda Select Europe otvorenom investicijskom fondu fondu s javnom ponudom ZB euroaktiv

4. Ugovori o pripajanju otvorenih investicijskih fondova Select Novčani, Select Eurobond i Select Europe, otvorenom investicijskom fondu ZB euroaktiv,

5. Potvrdu o iznosu temeljnog kapitala društva za upravljanje,

6. Popis povezanih osoba društva,

7. Obavijest o pripajanju,

8. Elaborate o pripajanju otvorenih investicijskih fondova Select Novčani, Select Eurobond i Select Europe otvorenom investicijskom fondu ZB euroaktiv,

9. Select Novčani – financijski izvještaj za godinu koja je završila 31. prosinca 2009., izvješće o stanju fonda i izvješće neovisnog revizora,

10. Select Eurobond – financijski izvještaji za godinu koja je završila 31. prosinca 2009., izvješće o stanju fonda i izvješće neovisnog revizora,

11. Select Europe – financijski izvještaji za godinu koja je završila 31. prosinca 2009., izvješće o stanju fonda i izvješće neovisnog revizora

12. ZB euroaktiv – financijski izvještaji za godinu koja je završila 31. prosinca 2009., izvješće o stanju fonda i izvješće neovisnog revizora,

13. ZB Invest d.o.o. za upravljanje investicijskim fondovima – Financijski izvještaji za godinu koja je završila 31. prosinca 2009. i izvještaj neovisnog revizora,

14. dokaz o uplaćenoj administrativnoj pristojbi i naknadi.

Fond preuzimatelj u postupku pripajanja bit će otvoreni investicijski fond s javnom ponudom ZB euroaktiv. Otvoreni investicijski fond s javnom ponudom ZB aktiv je započeo s radom 5. svibnja 2004. g. i osnovan je na neodređeno vrijeme. Rad Fonda odobren je Rješenjem Hrvatske agencije za nadzor financijskih usluga, klasa: UP/I-450-08/04-02/41, urbroj: 567-02-04,02 od 8. travnja 2004. godine.

Pripojeni fondovi u postupku pripajanja bit će otvoreni investicijski fondovi s javnom ponudom Select Novčani, Select Eurobond i Select Europe. Uvidom u podatke kojima Agencija raspolaže, utvrđeno je da je otvoreni investicijski fond s javnom ponudom Select Novčani započeo s radom 26. 5. 2003. godine. Rad Fonda odobren je rješenjem Hrvatske agencije za nadzor financijskih usluga, klasa: UP/I 450-08/03-02/107, urbroj: 576-02/03-2, od 10. travnja 2003. godine. Otvoreni investicijski fond s javnom ponudom Select Eurobond je započeo s radom 23. 1. 2001. Rad Fonda odobren je rješenjem Hrvatske agencije za nadzor financijskih usluga, klasa: UP/I-450-08/01-2/123, urbroj: 567-02/00-2 od 19. 12. 2001. godine. Otvoreni investicijski fond s javnom ponudom Select Europe započeo je s radom 18. 6. 2001. godine. Rad Fonda odobren je rješenjem Hrvatske agencije za nadzor financijskih usluga klasa: UP/I-450-08/01-02/27, urbroj: 567-02/00-4 od 31. svibnja 2001. godine.

Agencija je uvidom u dostavljene Elaborate o pripajanju fondova Select Novčani, Select Eurobond i Select Europe otvorenom investicijskom fondu s javnom ponudom ZB euroaktiv, utvrdila da su razlozi pripajanja nastali kao nastavak procesa konsolidacije ugovora o prijenosu upravljanja otvorenim investicijskim fondovima CAIB Invest d.o.o. na Društvo s obzirom na vrlo malu imovinu pod upravljanjem i malen broj klijenata u pripojenim fondovima.

Utvrđeno je da se provođenjem pripajanja ne umanjuju prava udjelničara sva četiri otvorena investicijska fonda s javnom ponudom. Sukladno članku 2. stavku 6. Pravilnika, Društvo imateljima udjela u pripojenim fondovima neće obračunati i naplatiti izlaznu naknadu.

Također je utvrđeno da je Društvo po donošenju odluke o pripajanju bez odgode javnim pozivom obavijestilo imatelje udjela u otvorenim investicijskim fondovima s javnom ponudom Select Novčani, Select Eurobond i Select Europe o namjeri pripajanja otvorenom investicijskom fondu s javnom ponudom ZB euroaktiv fondu što je sukladno odredbi članka 4. stavka 5. Pravilnika.

Budući da je u provedenom postupku utvrđeno, da je dosad provedeni, kao i namjeravani postupak pripajanja, u skladu s postupkom, uvjetima i načinom pripajanja propisanim odredbama Pravilnika, odlučeno je, na temelju odredbe članka 181. stavka 1. Zakona o investicijskim fondovima i članka 4. stavka 2. Pravilnika kao u točki 1. izreke Rješenja.

Kako je odredbom članka 4. stavka 3. Pravilnika predviđeno da u registru fondova, nakon provedenog postupka pripajanja, identifikacijski broj fonda koji se pripaja postaje identifikacijski broj fonda preuzimatelja, odlučeno je kao u točki 2. izreke rješenja.

Sukladno odredbi članka 8. stavka 3. Zakona o Hrvatskoj agenciji za nadzor financijskih usluga, ovo rješenje objavit će se u »Narodnim novinama«.

UPUTA O PRAVNOM LIJEKU

Protiv ovog rješenja žalba nije dopuštena, ali se protiv istog može pokrenuti upravni spor podnošenjem tužbe Upravnom sudu Republike Hrvatske u roku od 30 dana od dana primitka ovog rješenja.
