# Rješenje o imenovanju predsjednika i člana Upravnog vijeća Hrvatskog stočarsko selekcijskog centra

# VLADA REPUBLIKE HRVATSKE

Na temelju članka 30. stavka 4. Zakona o Vladi Republike Hrvatske ("Narodne
novine", broj 101/98) i članka 4. stavka 3. Uredbe o Hrvatskom stočarsko
selekcijskom centru ("Narodne novine", br. 63/94, 93/96 i 11/97), Vlada
Republike Hrvatske je na sjednici održanoj 4. studenoga 1999. godine donijela

## **RJEŠENJE**

### **O IMENOVANJU PREDSJEDNIKA I ČLANA UPRAVNOG VIJEĆA HRVATSKOG
STOČARSKO SELEKCIJSKOG CENTRA**

1. Imenuje se dr. IVAN KATALINIĆ predsjednikom Uprav-nog vijeća Hrvatskog
stočarsko selekcijskog centra.

2. Imenuje se dr. MARIJAN POSAVI članom Upravnog vijeća Hrvatskog stočarsko
selekcijskog centra.

Klasa: 080-02/99-01/151

Urbroj: 50304/2-99-02

Zagreb, 4. studenoga 1999.
