# Naredba o zabrani prometa i primjene sredstava za zaštitu bilja koja sadrže određene aktivne tvari

# MINISTARSTVO POLJOPRIVREDE, ŠUMARSTVA I VODNOGA GOSPODARSTVA

**3196**

Na temelju članka 12. stavka 2. Zakona o sredstvima za zaštitu bilja (»Narodne
novine«, br. 70/05), ministar poljoprivrede, šumarstva i vodnoga gospodarstva
donosi

## NAREDBU

### O ZABRANI PROMETA I PRIMJENE SREDSTAVA ZA ZAŠTITU BILJA KOJA SADRŽE ODREĐENE
AKTIVNE TVARI

*Sadržaj

*

Članak 1.

Ovom se Naredbom zabranjuje promet i primjena sredstava za zaštitu bilja (u
daljnjem tekstu: sredstva) koja sadrže određene aktivne tvari.

*Popis aktivnih tvari

*

Članak 2.

(1) Zabranjuje se stavljanje u promet i primjena sredstava koja sadrže jednu ili
više sljedećih aktivnih tvari:

| **Naziv aktivne  tvari ili skupine aktivnih tvari** |
| --- |
| **1. Živini  spojevi ** |
| alkil živini  spojevi |
| alkoksialkil i aril  živini spojevi |
| živin klorid (kalomel) |
| živin oksid |
| ostali anorganski  živini spojevi |
| **2. Postojani  organoklorni spojevi** |
| Kamfeklor |
| **3. Drugi spojevi** |
| Binapakril |
| 1,2-dibromoetan |
| 1,2-dikloroetan |
| dinoseb i njegove  soli |
| dinoseb acetat |
| dikofol, koji  sadrži manje od 78% p.p.1-dikofola ili više od 1 g/kg DDT i DDT srodnih  spojeva |
| etilen oksid |
| kaptafol |
| kvintozen, koji  sadrži više od 1 g/kg heksaklorobenzena ili više od 10 g/kg  pentaklorobenzena |
| malein hidrazid i  njegove soli, osim kolinove, kalijevih i natrijevih soli |
| malein hidrazid  kolinove, kalijeve i natrijeve soli koje sadrže više od 1 mg/kg  slobodnog hidrazina, izraženo na osnovi kiselinskog ekvivalenta |
| Nitrofen |

(2) Odredba stavka 1. ovoga članka ne odnosi se na sredstva
koja:

– aktivne tvari iz stavka 1. ovog članka sadrže u vidu zanemarivih onečišćenja
nastalih uslijed postupka proizvodnje, uz uvjet da nemaju štetni učinak na
ljude, životinje ili okoliš,

– se upotrebljavaju u svrhu istraživanja i razvoja ili u analitič­kim
postupcima,

– se izvoze.

*Iznimke

*

Članak 3.

(1) Iznimno od odredbi članka 2. ove Naredbe, nadležna uprava može dozvoliti
stavljanje u promet ili primjenu sredstava koja sadrže jednu ili više aktivnih
tvari iz članka 2. ove Naredbe na razdoblje od najviše 120 dana. Izvanredna
dozvola se izdaje samo u slučaju izvanrednih okolnosti koje može prouzročiti
štetni organizam, a nije ga moguće suzbiti ili ograničiti na odgovarajući način
registriranim sredstvom niti drugim mjerama.

(2) U slučajevima iz stavka 1. ovog članka, nadležna uprava će izvijestiti
Europsku komisiju i druge države članice Europske unije.

*Propisi koji se stavljaju izvan snage

*

Članak 4.

Stupanjem na snagu ove Naredbe prestaje važiti Naredba o zabrani prometa i
primjene sredstava za zaštitu bilja koja sadrže određene aktivne tvari (»Narodne
novine«, br. 28/06).

*Stupanje na snagu

*

Članak 5.

Ova Naredba stupa na snagu osmog dana od dana objave u »Narodnim novinama«, osim
odredbe članka 3. stavka 2. ove Naredbe koja stupa na snagu danom prijema
Republike Hrvatske u punopravno članstvo u Europskoj uniji.
