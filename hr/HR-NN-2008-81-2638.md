# Uredba o izmjenama i dopuni Uredbe o ciljnoj cijeni svježeg sirovog mlijeka

# VLADA REPUBLIKE HRVATSKE

2638

Na temelju članka 9. stavka 2. Zakona o poljoprivredi (»Narodne novine«, br.
66/2001 i 83/2002), Vlada Republike Hrvatske je na sjednici održanoj 10. srpnja
2008. godine donijela

## UREDBU

### O IZMJENAMA I DOPUNI UREDBE O CILJNOJ CIJENI SVJEŽEG SIROVOG
MLIJEKA

### Članak 1.

U Uredbi o ciljnoj cijeni svježeg sirovog mlijeka (»Narodne novine«, br.
156/2002, 153/2005 i 123/2007), u članku 2. stavak 1. mijenja se i glasi:

»Ciljna cijena mlijeka standardne kvalitete koje se stavlja na tržište Republike
Hrvatske, isporučenog na mjestu otkupa iznosi po kilogramu za:

– kravlje mlijeko 2,363 kuna

– ovčje mlijeko 5,842 kuna

– kozje mlijeko 3,035 kuna.«.

U stavku 2. brojevi: »7. i 8.« zamjenjuju se brojem: »i 7.«.

Članak 2.

U članku 3. riječ: »klasom« zamjenjuje se riječju: »razredom«.

Članak 3.

Članak 4. mijenja se i glasi:

»Obračun osnovne cijene mlijeka obavlja se na temelju postotne vrijednosti
težinskih udjela sadržaja mliječne masti i bjelančevina, te njihove jedinične
novčane vrijednosti prema formuli:

OCM = (M x v1) + (B x v2)

gdje je:

OCM = osnovna cijena mlijeka

M = postotna vrijednost težinskog udjela mliječne masti u mlijeku

B = postotna vrijednost težinskog udjela bjelančevina u mlijeku

v1 = novčana vrijednost masne jedinice, koja iznosi kod:

– kravljeg mlijeka 0,284 kuna

– ovčjeg mlijeka 0,341 kuna

– kozjeg mlijeka kuna 0,354 kuna

v2 = novčana vrijednost jedinice bjelančevina, koja iznosi kod:

– kravljeg mlijeka 0,410 kuna

– ovčjeg mlijeka 0,949 kuna

– kozjeg mlijeka kuna 0,691 kuna.“.

Članak 4.

Članak 5. mijenja se i glasi:

»Osnovna cijena mlijeka usklađuje se korištenjem ispravka vrijednosti za mlijeko
standardne kvalitete (3,7% mliječne masti i 3,2% bjelančevina za kravlje, 6%
mliječne masti i 4% bjelančevina za ovčje, odnosno 3,5% mliječne masti i 2,6%
bjelančevina za kozje mlijeko), zavisno od razreda u koji je razvrstano glede
broja mikroorganizama, a za kravlje mlijeko i na osnovi broja somatskih stanica
prema sljedećoj tablici:

| Kravlje  mlijeko | Ovčje i  kozje mlijeko |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- |
| Ispravak  vrijednosti | Razvrstavanje u razrede | Broj  mikroorganizama | Broj  somatskih stanica | Ispravak  vrijednosti | Razvrstavanje u razrede |  |
| Razred | Razred | Broj  mikroorganizama |  |  |  |  |
| 1,00 | I | ≤ 100.000 | ≤ 400.000 | 1,00 | I | ≤ 1.500.000 |
| 0,70 | II | > 100.000 | > 400.000 | 0,70 | II | > 1.500.000 |

### Članak 5.

Članak 6. mijenja se i glasi:

»Obračunata cijena kravljeg mlijeka umanjuje se za 0,2363 kuna po kilogramu, ako
ono sadrži manje od 3,2% mliječne masti ili manje od 3,0% bjelančevina.«.

Čanak 6.

Obračun cijene mlijeka izvršit će se prema odredbama ove Uredbe od 1. kolovoza
2008. godine.

Članak 7.

Ova Uredba stupa na snagu osmog dana od dana objave u »Narodnim novinama«.
