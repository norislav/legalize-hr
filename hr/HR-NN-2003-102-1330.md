# Rješenje o razrješenju glavne urednice "Narodnih novina" službenog lista Republike Hrvatske

# VLADA REPUBLIKE HRVATSKE

1330

Na teme­lju članka 30. stavka 4. Zakona o Vladi
Republike Hrvatske (»Narodne novine«, br. 101/98, 15/2000 i 117/2001) i članka
4. Zakona o preoblikova­nju Javnog poduzeća Narodne novine (»Narodne novine«,
broj 128/99), Vlada Republike Hrvat­ske je na sjednici održanoj 18. lip­nja
2003. godine donijela

## RJEŠENJE

### O RAZRJEŠENJU GLAVNE UREDNICE »NARODNIH NOVINA« SLUŽBENOG
LISTA REPUBLIKE HRVATSKE

Razrješuje se SNJEŽANA BAGIĆ dužnosti glavne
urednice »Narodnih novina« službenog lista Republike Hrvatske, radi odlaska na
novu dužnost.

Klasa: 080-02/03-02/49

Urbroj: 50304/2-03-01

Zagreb, 18. lip­nja 2003.
