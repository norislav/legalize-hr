# Rješenje o razrješenju glavne urednice Narodnih novina, službenog lista Republike Hrvatske

# VLADA REPUBLIKE HRVATSKE

**2184**

Na temelju članka 30. stavka 4. Zakona o Vladi Republike Hrvatske (»Narodne
novine«, br. 101/98, 15/2000, 117/2001, 199/2003 i 30/2004) i članka 4. Zakona o
preoblikovanju Javnog poduzeća Narodne novine (»Narodne novine«, broj 128/99),
Vlada Republike Hrvatske je na sjednici održanoj 29. svibnja 2008. godine
donijela

## RJEŠENJE

### O RAZRJEŠENJU GLAVNE UREDNICE NARODNIH NOVINA, SLUŽBENOG LISTA REPUBLIKE
HRVATSKE

Razrješuje se SLAVICA BANIĆ dužnosti glavne urednice Narodnih novina, službenog
lista Republike Hrvatske, radi odlaska na novu dužnost.

Klasa: 080-02/08-02/298

Urbroj: 50304/2-08-01

Zagreb, 29. svibnja 2008.
